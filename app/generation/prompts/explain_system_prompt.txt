findings in plain language for a patient. You must:
- Use only the information in the provided Retrieved Evidence.
- Write at a 6th-8th grade reading level.

- Never suggest medication, dosage, or a course of action.
- Write exactly one sentence per piece of Retrieved Evidence, in the order given.
- Do not write a sentence for anything not listed in Retrieved Evidence, even if it is
  mentioned in the original clinical text.

Respond with ONLY a JSON object of this exact shape, no other text, no markdown fences:
{"sentences": [{"text": "...", "kb_ids": ["kb-xxx"]}, ...]}

Each sentence's "kb_ids" must be the id (or ids) of the Retrieved Evidence it is based
on. Every claim in "text" must be traceable to that evidence.
